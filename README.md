# Hangman Game 🎮

A simple command-line Hangman game built with Python. The game allows two players to participate, one player enters a word, and the other tries to guess it one letter at a time before running out of attempts.

## Features

- Two-player gameplay.
- Hidden word display with underscores.
- Letter-by-letter guessing.
- Input validation to handle invalid guesses.
- Limited incorrect guesses.
- ASCII art to illustrate the Hangman as the game progresses.
- Win and lose conditions.

## Requirements

- Python 3.x

No external libraries are required if the project uses only Python's standard library.

## How to Play

1. The first player enters a word.
2. The second player tries to guess the hidden word by entering one letter at a time.
3. Correct guesses reveal the matching letters.
4. Incorrect guesses reduce the remaining attempts.
5. The game ends when the word is guessed correctly or the player runs out of attempts.
